# 목록·집합·사전 고르기

배열은 순서를 가진 **목록**, Set은 중복 없는 **집합**, Map은 키와 값을 연결하는 **사전**으로 표현합니다. 값과 목적에 맞춰 자료구조를 고르면 코드의 뜻이 더 명확해집니다.

```hgs
점수들은 [75, 92, 88, 92]이다
통과점수는 골라내기(점수들, 점수 => 점수 >= 80)이다
서로다른점수는 집합(통과점수)이다
출력(내림차순(목록으로(서로다른점수)))
```

`배열`을 나타내는 타입은 `목록<숫자>` 또는 `숫자[]`입니다. 집합은 `집합<문자열>`, 사전은 `사전<문자열, 숫자>`로 적습니다. 함수의 매개변수에 타입을 쓰면 잘못된 값이 들어오는 호출을 빌드 단계에서 찾을 수 있습니다.

```hgs
재고: 사전<문자열, 숫자>는 사전()이다
사전에담기(재고, "사과", 3)
사전에담기(재고, "배", 5)
출력(키목록(재고), 사전에서읽기(재고, "사과"))
```

## 원본과 복사본

`정렬`, `오름차순`, `내림차순`, `골라내기`, `각각바꾸기`, `뒤집기`, `잘라내기`는 원본 배열을 바꾸지 않습니다. `추가`, `집합에추가`, `집합에서삭제`, `사전에담기`, `사전에서삭제`는 원본을 바꿉니다. 함수별 참조 문서에서 확인하세요.

얕은 복사는 바깥 그릇만 새로 만듭니다. 안쪽 객체는 공유합니다. 깊은 복사는 복제 가능한 안쪽 값까지 별도로 만듭니다.

```hgs
원본은 [{ 점수: 10 }]이다
얕은복사본은 얕게복사(원본)이다
깊은복사본은 깊게복사(원본)이다
얕은복사본[0].점수 = 20
출력(원본[0].점수, 깊은복사본[0].점수)
```

결과는 `20 10`입니다. 깊은 복사는 함수·DOM 노드 등 복제 불가능한 값에 오류를 냅니다. 객체를 중복 제거하거나 집합에 넣을 때에는 내용이 같아도 참조가 다르면 서로 다른 값입니다.

## 정렬 기준 쓰기

```hgs
학생들은 [{ 이름: "하늘", 점수: 88 }, { 이름: "바다", 점수: 92 }]이다
점수순은 기준정렬(학생들, 학생 => 학생.점수, "내림차순")이다
출력(점수순)
```

숫자는 크기로, 문자열은 한국어 locale의 자연 정렬로 비교합니다. 같은 키의 항목은 원래 순서를 유지합니다. 더 복잡한 순서는 `정렬(목록, 비교함수)`로 표현하며 비교 함수는 음수·0·양수를 반환해야 합니다.

## 비용을 알고 쓰기

목록 변환·필터·복사는 항목 수에 비례한 시간과 새 배열 메모리가 필요합니다. 정렬은 일반적으로 O(n log n), 집합·사전 검색은 평균적으로 상수 시간에 가깝습니다. 깊은 복사는 중첩 데이터 전체의 시간·메모리를 사용합니다. `기준정렬`은 기준 함수를 항목마다 한 번만 호출합니다. 큰 반복에서 불필요하게 복사하지 말고, 2초 제한의 웹 데모와 일반 Node 실행을 구분하세요.

## 문장처럼 적기

정렬·복사·중복 제거는 값 자리에서 다음 문장으로도 적을 수 있습니다. 함수 호출과 같은 결과이며, 정해진 표현만 지원합니다.

```hgs
점수들은 [88, 92, 88]이다
점수순은 점수들을 내림차순으로 정렬한 값이다
서로다른값은 점수들에서 중복을 제거한 값이다
독립본은 점수들을 깊게 복사한 값이다
출력(점수순, 서로다른값, 독립본)
```
