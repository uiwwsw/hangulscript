# 한글 프로그래밍 함수 만들기

입력을 받아 결과를 돌려주는 코드를 재사용합니다. 한글스크립트의 정해진 문장형 문법으로 작성하고 JavaScript로 변환해 실행합니다.

## 실행 예제

```hgs
인사(이름: 문자열)를 정의한다:
    돌려주기 "안녕, " + 이름

출력(인사("우리말"))
```

## 예상 출력

```text
안녕, 우리말
```

## 직접 바꿔 보기

함수는 이름을 붙인 처리 과정입니다. 정의하는 것만으로 실행되지 않으며 `인사("우리말")`로 호출합니다. 인수를 바꾸어 반환되는 문자열의 차이를 확인하세요.
