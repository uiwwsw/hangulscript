# 설치 없이 한글로 코딩하기

한글스크립트(HangulScript)는 한글 문장과 들여쓰기로 작성한 코드를 JavaScript로 변환하는 프로그래밍 언어입니다. 한글 스크립트를 처음 찾았다면 온라인 플레이그라운드에서 시작할 수 있습니다. 일반적인 한국어 질문을 모두 이해하는 도구는 아니며 정해진 문법을 사용합니다.

## 온라인 실행 순서

1. [한글 코딩 플레이그라운드](/playground/)를 엽니다.
2. 아래 코드를 입력합니다.
3. 실행 버튼을 누릅니다.
4. 콘솔에서 `안녕, 세상!`을 확인합니다. 변환된 JavaScript도 함께 볼 수 있습니다.

```hgs
출력("안녕, 세상!")
```

Node.js나 편집기를 설치하지 않고 브라우저에서 먼저 확인할 수 있습니다. 코드는 시간 제한이 있는 격리 환경에서 동작합니다. 파일·서버·외부 네트워크를 사용하는 Node 프로그램의 실행 환경과는 다릅니다.

## 한글 프로그래밍 언어 기초

- [변수와 자료형](variables.md): 이름을 붙여 숫자와 문자열을 저장합니다.
- [조건문](conditions.md): 조건을 만족할 때만 실행합니다.
- [반복문](loops.md): 목록의 값을 하나씩 처리합니다.
- [함수](functions.md): 입력을 받아 결과를 돌려줍니다.

예제를 실행한 뒤 값과 조건을 바꾸어 예상 출력과 비교하세요.

## 프로젝트에서 사용하려면

[설치와 첫 프로그램](start.md)에서 npm 설치·Node 실행·JavaScript 빌드를 이어갈 수 있습니다. [VS Code 설정](/docs/vscode/)과 [React·Vue 연결](/docs/frameworks/)도 제공합니다. 미구현 기능과 제약은 [지원 안내](/docs/support/)에서 확인하세요.
