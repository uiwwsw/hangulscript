KOREAN PROGRAMMING LANGUAGE

Write in Korean.
Run as JavaScript.

HangulScript (한글스크립트) is a Korean sentence-style programming language. Write .hgs files with indentation, check types, and compile to JavaScript and .d.ts declarations.

We want programming to feel welcoming: a place where people can express ideas in familiar Korean and enjoy bringing them to life. Natural Korean expressions are our long-term goal; the current language follows explicit grammar.

이름은 "세상"이다
출력("안녕, " + 이름)

This declares a name and prints “Hello, world” in Korean. Try the online playground → The playground interface and full documentation are currently in Korean.

Get started

Requires Node.js 20.19 or later.

npm install --save-dev @uiwwsw/hangulscript
npx ksc run main.hgs
npx ksc build main.hgs --out-dir output

The build emits executable JavaScript and TypeScript declaration files. A shared Vite plugin lets React and Vue projects import .hgs modules. Framework integration guide (Korean).

HangulScript for Visual Studio Code

The official extension provides syntax highlighting, formatting, type diagnostics, scoped completion, hover information, go to definition and a ㅎ file icon.

code --install-extension uiwwsw.hangulscript-vscode

Install from Visual Studio Marketplace →

Current scope and roadmap

HangulScript 0.8 includes 61 Korean helpers for collections, sorting, copies, strings, numbers, checks and basic UI controls. The compiler and type checker work without an AI API.

Arbitrary natural-language execution, full JavaScript/TypeScript source compatibility, native compilation, automatic imports and full editor refactoring are not currently supported. The language is in the 0.x series and its grammar and APIs may change.
