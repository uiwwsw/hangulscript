01 / 직접 해보기

작은 문장, 움직이는 프로그램.

● 브라우저 안에서 실행

도구 입력값을 바꾸면 예제 코드가 다시 만들어집니다. 코드를 직접 편집하면 입력란은 숨겨집니다.

main.ks
main.ts
실행 결과실행을 눌러 주세요
여기에 프로그램의 출력이 나타납니다.

공유된 코드는 자동 실행하지 않습니다. 실행은 격리된 환경에서 최대 2초 동안 진행됩니다. 브라우저 데모는 네트워크·DOM·외부 모듈을 제공하지 않습니다.

02 / 문법의 출발점

외울 것은 줄이고, 뜻은 또렷하게.

01

문장으로 선언

나이는 20이다
이름은 "하늘"이다

조사 은·는과 어미 이다로 값을 선언합니다. 값은 다시 대입할 수 있습니다.

02

들여쓰기로 흐름 표현

각 수를 범위(1, 4)에서:
    만약 수 > 1 이라면:
        출력(수)

콜론 뒤 블록은 공백으로 들여씁니다. 범위의 끝값은 포함하지 않습니다.

03

이질감 없는 기본 기능

합계([10, 20, 30])
정렬([3, 1, 2])
길이("한글")

출력·길이·합계·평균·최솟값·최댓값·반올림 등 15개 기본 함수를 제공합니다.

함수, 조건, 반복 문법 더 보기
인사(이름)를 정의한다:
    돌려주기 "안녕, " + 이름

만약 나이 >= 20 이라면:
    출력("성인")
아니고 나이 >= 14 이라면:
    출력("청소년")
아니면:
    출력("어린이")

동안 나이 < 25:
    나이 = 나이 + 1
    만약 나이 == 23 이라면:
        멈추기

문장형 파일은 문장으로 시작으로 명시할 수 있습니다. 자유 자연어 해석, Python 호환 실행기, 전체 TypeScript 문법 지원을 의미하지는 않습니다. 문자열 길이는 JavaScript의 UTF-16 기준이며 정렬은 숫자 목록을 복사해 정렬합니다.
