● 브라우저 안에서 실행
main.hgs
UI 미리보기코드의 입력창과 버튼이 여기에 나타납니다

실행하기를 눌러 화면을 만들어 보세요.

버튼을 누를 때 현재 입력값으로 프로그램을 처음부터 실행합니다. 입력값을 바꾼 뒤 도구 안의 버튼을 눌러 보세요.

기본 출력은 JavaScript입니다. CLI의 ksc build main.hgs는 main.js와 타입 선언 main.d.ts를 함께 만듭니다. 변환된 코드는 실제 실행하는 코드와 같습니다. 출력은 console.log로 변환하며 필요한 한글 표준 함수 정의도 함께 표시합니다. UI 함수는 데모의 화면 연결 환경이 필요합니다.

콘솔 Console
실행을 눌러 주세요
출력과 오류가 여기에 표시됩니다.

공유된 코드는 자동 실행하지 않습니다. 실행은 격리된 환경에서 최대 2초 동안 진행됩니다. 브라우저 데모는 네트워크·직접 DOM 접근·외부 모듈을 제공하지 않습니다. 화면은 제한된 UI 함수로 생성합니다.
